1. TỔNG QUAN DỰ ÁN & CÔNG NGHỆ (TECH STACK)
--------------------------------------------------------------------------------
- Đối tượng: Học sinh THPT yêu thích Lập trình Thi đấu (Competitive Programming), 
  Thuật toán & Công nghệ.
- Công nghệ cốt lõi: HTML5, CSS3 (Biến CSS linh hoạt), JavaScript (Vanilla JS).
- Tích hợp AI (Client-side): Sử dụng Transformers.js / TensorFlow.js chạy trực tiếp 
  trên trình duyệt (không cần server backend) để trả lời thắc mắc của người dùng.

2. HỆ THỐNG GIAO DIỆN & MÀU SẮC (THEME SWITCHER)
--------------------------------------------------------------------------------
Website hỗ trợ chuyển đổi linh hoạt giữa 3 chế độ (Lưu bằng localStorage):
- Chế độ Sáng (Light Mode): Nền trắng sáng/xám nhạt (#f8fafc), chữ đậm (#0f172a), 
  điểm nhấn xanh lam (#2563eb).
- Chế độ Tối (Dark Mode): Nền xanh đen sâu kiểu Night Owl (#011627), chữ sáng (#f8fafc), 
  điểm nhấn xanh ngọc Cyan (#22d3ee).
- Chế độ Hệ thống (System Mode): Tự động đồng bộ với cài đặt thiết bị/trình duyệt 
  thông qua CSS Media Query (@media prefers-color-scheme).
